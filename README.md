# File-System-BFS-DFS
File System Representation and Search Using BFS and DFS

Project Description

This project represents a file system as a graph using an adjacency matrix. Each file or directory is represented as a node, and connections are represented as edges.

BFS and DFS algorithms are implemented to search for a specified file from a given starting node.

Objectives

- To represent a file system using a graph.
- To implement BFS and DFS algorithms.
- To display the traversal order.
- To identify whether a file is found or not.

Technologies Used

- Programming Language: C
- Editor: Visual Studio Code
- Compiler: GCC
- Graph Representation: Adjacency Matrix

Algorithms Used

1. Breadth First Search (BFS)

BFS visits nodes level by level using a queue.

2. Depth First Search (DFS)

DFS explores one path deeply before backtracking. It uses recursion.

How to Run

Compile:

gcc filesystem.c -o filesystem.exe

Run:

.\filesystem.exe

Conclusion

This project demonstrates the use of graph representation and BFS and DFS algorithms for searching files in a file system.
